# jumtueksperti.lv

Static website for SIA "Jumtu ekspertīžu birojs" (www.jumtueksperti.lv), in Latvian (`/`) and Russian (`/ru/`).

**Live preview:** https://bumerss.github.io/jumtueksperti-website/

The site is plain pre-built HTML/CSS: no build step and no server code. Upload the whole folder as is.

## Deploy

**Netlify** or **Cloudflare Pages** (both free):

1. Connect this repository (or drag and drop the folder).
2. Build command: none. Publish directory: `/` (repository root).
3. Add the custom domain `www.jumtueksperti.lv`.

`_headers` (security and caching headers) and `_redirects` (non-www → www, 404 pages) are read automatically by both hosts. On Cloudflare Pages, set the non-www → www redirect in the dashboard (Rules → Redirect Rules); see the comment in `_redirects`.

## Before launch

- The service request form (`kontakti/`) sends to the URL in its `data-endpoint` attribute (e.g. a Formspree form). While empty, it opens the visitor's e-mail app with a prepared message. The short "Ātra saziņa" form still posts to `/api/contact`, which does not exist here.
- After launch, submit `https://www.jumtueksperti.lv/sitemap.xml` in Google Search Console and Bing Webmaster Tools.

## Editing Latvian pages

The Latvian home, services, objects, about and certificates pages are generated by `tools/build-lv.mjs` (content is in its data blocks). Edit that file and run `node tools/build-lv.mjs`; do not hand-edit those HTML files.

## Structure

- `index.html`, `*/index.html`: Latvian pages
- `ru/`: Russian pages
- `_astro/`: stylesheet and Open Sans font files
- `assets/`: logos, photos, certificates (personal data redacted), map tiles
- `sitemap.xml`, `robots.txt`, `llms.txt`: search engine and AI crawler files

## Images

Pages use WebP copies from `assets/img/` (originals stay in `assets/objects/`, `assets/certificates/`, `assets/brand/`). Photos have two widths so phones load the smaller one (`srcset`, set up in `WEBP` in `tools/build-lv.mjs`). To add a new photo, make both widths with ffmpeg (`-q:v` sets quality; `-quality` is ignored by this encoder), add it to `WEBP` and run `node tools/build-lv.mjs`:

```
ffmpeg -i photo.jpg -vf "scale='min(1400,iw)':-2:flags=lanczos" -c:v libwebp -q:v 82 -compression_level 6 -preset photo assets/img/photo-1400.webp
ffmpeg -i photo.jpg -vf "scale='min(800,iw)':-2:flags=lanczos"  -c:v libwebp -q:v 82 -compression_level 6 -preset photo assets/img/photo-800.webp
```
